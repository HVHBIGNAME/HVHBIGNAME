# HVH / BIGNAME

Портфолио HVHBIGNAME: шесть связанных SVG-секций, один ритм, четыре проекта.
В README остаются картинки и сворачиваемый журнал. Описание, стек, статус и
мини-кнопка каждого проекта находятся непосредственно в его карточке.

## Знак и композиция

Монограмма нарисована контурами: две зеркальные **H** с внешними срезами,
между ними медная **V**. Два встречных импульса сходятся в центре и дают
короткую вспышку осколков — отсылка к HVH. Сами буквы остаются неподвижными.
Статичные версии 512 × 512 находятся в `assets/hvh-mark-{dark,light}.svg`.
Все версии используют одни и те же контуры из `scripts/brand.py`.

Матовые графитовые поверхности, небольшие скругления, спокойные цвета и
асимметричная обложка. В emberdeck и OpenCode Pocket сцена расположена слева,
в BCore и SoftDownloader — справа. Тексты и мини-кнопки всегда неподвижны.

## Единый SVG-атлас

`assets/profile-dark.svg` и `assets/profile-light.svg` содержат всю композицию.
README показывает её именованные фрагменты:

| Фрагмент | Содержимое |
| :-- | :-- |
| `#hero` | Обложка и стек |
| `#bcore` | Генерация воксельного мира и свет |
| `#minecraft-panel` | Консоль и графики emberdeck |
| `#softdownloader` | Каталог, очередь и установка пакетов |
| `#opencode-pocket` | Компьютер, QR и мобильный диалог |
| `#signal` | Настоящая публичная активность GitHub за 90 дней |

Фрагменты задаются через SVG `<view>`. У всех один размер **1200 × 420**:
это сохраняет одинаковое соотношение сторон при переключении видов общего
изображения и изменении ширины браузера. У корня атласа намеренно нет `height`;
высоту отдельной картинки определяет выбранный `viewBox`.
Параметр `?v=hvh2` в README обновляет кэш после смены оформления; все шесть
видов каждой темы по-прежнему используют один URL ресурса.

Общая световая линия, пульс и фазы иллюстраций живут в одном SVG-документе.
Основной цикл — **16 секунд**, пульс — 4 секунды. Один ресурс используется
всеми карточками, поэтому загрузка отдельных иллюстраций не создаёт разные
скорости анимации. Шрифтовые файлы, внешний JavaScript и сервисы картинок не нужны.

### Сценарии движения

- **BCore:** 44 блока с травой, грунтом и включениями падают на свои места —
  сначала основание, затем верхние слои. Приземления сопровождаются пылью,
  после сборки вырастают два дерева и проходит тонкий контур света.
- **emberdeck:** появляется ядро сервера, по очереди запускаются два серверных
  блока, заполняются индикаторы и рисуется график с активной конечной точкой.
  Корпус дополнен крепежом, вентиляционными прорезями, вращающимся вентилятором
  и небольшими угольками. График в этой иллюстрации — часть сценария, не телеметрия.
- **SoftDownloader:** маленькие пакеты летят из коробки в ячейки каталога;
  каждая установка заканчивается галочкой. Общая полоса прогресса заполняется
  до финального подтверждения. У пакетов есть следы движения, у коробки —
  лента и штрихкод; установка сопровождается коротким разлётом частиц.
- **OpenCode Pocket:** QR сканируется, соединение подтверждается, пакет
  передаётся на телефон. Затем по очереди появляются три сообщения
  с индикатором набора между ответами. У передачи есть след и вспышка при
  доставке; телефон дополнен боковыми клавишами и терминальной пиктограммой.

Текст и кнопки остаются неподвижными. Без анимации показаны завершённые сцены,
а служебные летающие пакеты, частицы и индикаторы набора скрыты. Частицы
детерминированы и привязаны к событиям общего цикла через CSS-переменные.

## Палитра и адаптация

Графит / тёплый светлый фон; приглушённый зелёный для BCore, медь для emberdeck,
стальной голубой для SoftDownloader и серо-сиреневый для OpenCode Pocket.
Тема выбирается стандартным `<picture>` через `prefers-color-scheme`.
При ширине картинки до 600 px SVG переключает композицию: крупный текст,
крупная кнопка и фоновая иллюстрация. `prefers-reduced-motion` останавливает движение.

Каждая карточка обёрнута одной HTML-ссылкой в README. Встроенная мини-кнопка
и остальная площадь карточки открывают один и тот же проект.

## Исходники и сборка

- `scripts/design.py` — палитры, описания, композиция, CSS-анимации, SVG-атлас.
- `scripts/illustrations.py` — векторные иллюстрации без внешних ресурсов.
- `scripts/brand.py` — контуры HVH, встречные импульсы и статичный экспорт знака.
- `assets/activity.json` — 90 уже опубликованных дат и счётчиков contributions.
- `scripts/generate_profile.py` — получение новых данных GitHub и обновление журнала.

Пересобрать оформление с сохранёнными данными, без токена и обращения к API:

```sh
python scripts/design.py
```

## Автообновление

GitHub Actions запускается каждый час на 17-й минуте, при изменении README /
скриптов / workflow, а также вручную. Возможны задержки планировщика и обработки
активности на стороне GitHub. Используется встроенный временный `GITHUB_TOKEN`.

Генератор обновляет оба атласа, публичный кэш `activity.json` и таблицу между
`<!-- PROJECTS:START -->` / `<!-- PROJECTS:END -->`. Даты — UTC. Contributions
включают коммиты, issues, pull requests и reviews; нулевые дни остаются нулевыми.
При неизменных данных новый коммит не создаётся. Все запросы и отрисовка должны
успешно завершиться до записи файлов; ошибка API сохраняет предыдущий результат.

```sh
python -m unittest discover -s scripts -p 'test_*.py' -v
```

Для локального получения новых данных передайте `GITHUB_TOKEN` или `GH_TOKEN`
в окружение процесса и выполните `python scripts/generate_profile.py`.
