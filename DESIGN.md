# Vibe in. Systems out.

Персональное оформление HVHBIGNAME: инженерный чертёж, крупная типографика,
изометрическое ядро и аккуратная motion-графика.

## Визуальная система

| | Dark | Light |
| :-- | :-- | :-- |
| Фон | `#101310` | `#f3f2e9` |
| Текст | `#f0f2e8` | `#20271b` |
| Акцент | `#d2ff5a` | `#496817` |
| Второй акцент | `#c0a6ff` | `#7050b4` |

Все иллюстрации — локальные SVG, сгенерированные `scripts/design.py`.
Шрифтовые файлы, сторонние сервисы картинок и JavaScript не требуются.
Светлая и тёмная версии выбираются через `<picture>` по `prefers-color-scheme`.
При ширине изображения до 600 px обложка перестраивается: крупнее имя и заголовок,
компактнее иллюстрация. Этот медиа-запрос находится внутри SVG, чтобы не конфликтовать
с переключателем тем GitHub.
Анимация учитывает системную настройку `prefers-reduced-motion`.

Пересобрать обложки:

```sh
python scripts/design.py
```

## Автообновление

`scripts/generate_profile.py` обновляет:

- две версии графика contributions за 90 дней;
- таблицу внутри `<!-- PROJECTS:START -->` / `<!-- PROJECTS:END -->`.

Тексты, избранные проекты и иллюстрации редактируются независимо от журнала.
Журнал содержит только публичные, неархивные авторские репозитории.
Даты push абсолютные, в UTC. Метрики относятся к contributions GitHub,
а не только к коммитам. Нулевые дни остаются нулевыми.

Workflow запускается каждый час на 17-й минуте (возможна задержка планировщика GitHub),
при изменении README / скриптов / workflow, а также вручную через Actions.
Используется встроенный `GITHUB_TOKEN`; отдельный PAT не нужен.
График собирается из GitHub API: новая активность появится после её обработки GitHub
и следующего запуска workflow. При неизменных данных новый коммит не создаётся.
При ошибке API запуск завершается с ошибкой, сохраняя опубликованные изображения.

Проверить генератор:

```sh
python -m unittest discover -s scripts -p 'test_*.py' -v
```

Для локального обновления данных передайте `GITHUB_TOKEN` или `GH_TOKEN`
в окружение процесса и выполните `python scripts/generate_profile.py`.
